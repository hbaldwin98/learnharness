# Readings

Opt-in companion documents beside your lessons — primers, overviews, deep dives,
recaps and deep dives on knowledge-map picks — written in the background by a writer
from model knowledge or web research (cited pages must have been fetched), with
**Discuss**: ask about a passage or in a side chat; each finished exchange in a
session-anchored reading reaches the teacher as a note (never a wake).

Core plugin. Uses fork extension points E1 (markers), E2 (session panel) and E5
(transcript and graph selection). On first activation it imports the fork's old
`data/readings` and `data/reading-discussions` stores into its data directory
(idempotent; the old files are never changed).

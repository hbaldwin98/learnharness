# Graphite

Style-only Core plugin: the Graphite chrome for LearnHarness.

- Geist and Geist Mono (bundled under `assets/fonts`, SIL OFL 1.1).
- Sentence-case labels, deeper shadows, a 264px sidebar, a tighter settings
  dialog, and a centred 760px transcript.
- A session top-bar action cycles the transcript width: 760, 960, 1160 and
  1360px. The choice is saved in this browser.

The stylesheet sets no colours. It reads the active theme's tokens, so it works
with any theme, light or dark. The Graphite palette is `theme/graphite.json`
(import it in Settings → Appearance → Theme).
